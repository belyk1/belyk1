# Kyle Burroughs

I design and direct the build of AI agent systems: teams of agents on different model engines that coordinate, check each other's work and improve under measurement.

## What I'm building

- **Apollo** — a harness that supervises agent loops from many engines as one team. Rust core, TypeScript/React interface.
- **Athena** — an adaptive learning agent that follows each learner, cites its sources and tests its own output.
- **Perseus** — research toward a learned generator for production-grade 3D geometry.
- **Game agents** — agents that build game mods, and a benchmark of how well they control a game.
- **Sketch and Juno** — creative agents for narrative and workflow.

The full write-ups, design decisions and measured results are in **[ai-systems-portfolio](https://github.com/belyk1/ai-systems-portfolio)**. The source repositories are private, and I'm happy to walk through any of them.
